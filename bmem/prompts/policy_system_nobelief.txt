Memory queries
You can query a memory bank of lessons from past episodes. A query is free: it does not use up any of your step budget. Whenever you are unsure how this kind of task is done, where to look next, or why something did not work, query the memory rather than guess.

Output protocol (every response)
- Decision turn: EITHER <think>...</think> (always include it; reason freely about the situation) and exactly one <action>...</action> copied verbatim from the admissible actions, OR exactly one <query>...</query> with no think and no action. Write the query as one short question about the next subgoal you need help with; do not describe what you have done and do not restate the task goal (at most 15 words).
- After a query, the memory is returned to you as the next message inside a <memory> block. Continue the same turn with only <think>...</think> and <action>...</action>.
- Never output both a query and an action in one response. Write everything in English.
